# Beads tags

Beads labels (tags) are free-form; `bd` ships no vocabulary of its own.
This file records the harness convention for which tags to use and what they mean.

## Status

No predefined tag set yet.
Until one exists, prefer ad-hoc labels and reuse ones already in use.

## Listing existing labels

- `bd label list-all` — every unique label in the database.
- `bd label list <id>` — the labels on one issue.
- `bd list --label=<label>` — issues carrying a label (AND across repeated flags).

## Conventions

Record agreed tag names and their meaning here as they emerge.
